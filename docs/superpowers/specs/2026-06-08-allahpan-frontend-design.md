# AllahPan 前端设计语言

> 引导性规范，非严格约束。实现时保持整体氛围一致即可，细节可自由发挥。

---

## 一、设计定位

家庭共享云盘，用户为家庭成员（含非技术用户）。关键词：**温馨、简洁、可信赖**。避免企业产品的冷峻感，也不走儿童产品的幼稚路线。

## 二、色彩

**基调：暖白底色 + 木色点缀。**

| 角色 | 参考色值 | 说明 |
|------|----------|------|
| 页面底色 | `#FAF7F2` | 暖米白，非纯白 |
| 卡片/内容区 | `#FFFFFF` | 白卡片浮于暖底上 |
| 侧边栏 | `#F5EFE6` | 比底色略深一阶，自然区分 |
| 主文字 | `#3D3226` | 暖黑，不用 `#000` |
| 辅助文字 | `#8B7E6E` | 暖灰 |
| 边框/分割线 | `#E8E0D5` | 若隐若现 |
| 主色调 | 木色系 `#C4946B` | 按钮、选中态、链接 |
| 主色 hover | `#A87D5A` | 加深 |

功能色（成功/警告/危险）可沿用 Element Plus 默认，不做定制。

**Element Plus 覆盖：** 把 `--el-color-primary` 设为主色调即可，其余变量按需覆盖。

## 三、布局

**侧边栏（200px）+ 内容区。侧边栏可折叠至 64px。**

- 侧边栏：Logo → 导航菜单（图标+文字，选中态木色背景+左侧色条）→ 底部用户信息
- 顶部栏：面包屑 + 搜索入口 + 视图切换（网格/列表），底部极细分割线
- 内容区：24px 内边距，顶部工具栏粘性定位

## 四、卡片

网格布局，`minmax(160px, 1fr)` 自适应列数。卡片约 180px 高，上部缩略图/图标预览区 + 下部文件名+元信息。圆角 16px，暖色微阴影。hover 时微微上浮 + 阴影加深。

## 五、字体

优先系统中文字体栈：苹方 → 冬青 → 微软雅黑 → 思源黑体。标题 18-24px/600，正文 14px/400，辅助 12px/400。文件名超长截断 + Tooltip。

## 六、动效

适度弹性，不泛滥。弹窗打开有微弹性缩放（250ms），卡片 hover 平滑过渡（200ms），页面切换淡入（150ms）。按钮点击有轻微按压反馈。列表增删用 `<TransitionGroup>` 过渡。

## 七、组件风貌

- **按钮：** 圆角 10px，主按钮木色填充。每行最多一个主按钮。危险操作用红色描边文字按钮。
- **输入框：** 圆角 10px，聚焦时木色边框 + 淡木色外发光。
- **弹窗：** 圆角 16px，暖色遮罩，底部按钮右对齐（取消左/确认右）。
- **图标：** 统一用 `@element-plus/icons-vue` 或 SVG，禁用 Emoji。
- **文件图标：** 文件夹木色 Folder 图标，图片优先显示缩略图（失败则 Picture 图标），视频 VideoCamera + 时长角标，文档按扩展名区分图标。
- **空状态：** 居中 SVG 图标 + 引导文字 + 操作按钮，不用 Emoji。
- **右键菜单：** 圆角 10px，暖色阴影，图标+文字菜单项。

## 八、加载与反馈

- 列表加载用骨架屏（Element Plus `<el-skeleton>`），不用全屏 Loading
- 上传有线性进度条，完成时文件名短暂高亮
- 删除需确认弹窗，不直接用浏览器 confirm
- 收藏切换有弹性缩放动画
- 错误不弹窗打断，内联提示 + 重试按钮
- 全局加载用顶部 3px 进度条，非全屏遮罩

## 九、响应式

桌面优先（侧边栏布局）。平板（<1024px）侧边栏默认折叠。手机（<768px）侧边栏变底部 TabBar，卡片列数减少。

## 十、开放指引

以上为氛围参考，以下给实现者自由：

- 具体色阶微调、阴影参数、间距数值 —— 按实际视觉效果判断
- 文件类型图标配色方案 —— 自行设计，保持柔和协调
- 登录页、设密码页的视觉创意 —— 可以更有"家庭归属感"
- 上传弹窗拖拽区的视觉设计 —— 可自由发挥
- 任何以上未覆盖的细节 —— 以"温馨简洁"为准绳，自行决断
