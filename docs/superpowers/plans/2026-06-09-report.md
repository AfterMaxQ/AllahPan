**Date:** 2026-06-09
**Scope:** Static code review (31 Java source files) + Runtime verification (31 API endpoints + edge cases + stress tests)

## Executive Summary

后端整体架构设计合理，核心 CRUD 操作稳定（上传/下载/重命名/移动/删除/回收站/分享/收藏均通过），文件处理管线正常（缩略图→OCR→ES索引）。发现 **10 个 Bug**，其中 **2 个严重（P0）** 在生产环境会直接导致功能不可用。

## 修复建议（按优先级）

### 立即修复

1. **`EsIndexServiceImpl.java:130`** — `selectByExample` → `selectByExampleWithBLOBs`
2. **`ApiException.java:14`** — 删除 `this.resultCode = ResultCode.FAILED;`（让 handler 走 `e.getMessage()` 路径）
3. **`GlobalExceptionHandler.java`** — 加 `@ExceptionHandler(Exception.class)` 兜底
4. **`FileController.java:92`** — 加空值检查：`Asserts.isTrue(file != null, "文件不存在");`
5. **`FileServiceImpl.java:deleteChildren`** — 软删除时在 `deleteTime` 加毫秒偏移避免同名唯一约束冲突

### 计划修复

6. **`SecurityConfig.java`** — `/api/share/**` 限制为 GET only
7. **`FileServiceImpl.java:renameFile`** — 文件夹重命名时更新 storageKey
8. **`FileServiceImpl.java:listTrash`** — 加 `uploaderId` 过滤
9. **`FavoriteServiceImpl.java:addFavorite`** — 加文件存在性检查
10. **`FileSystemWatcher.java:487`** — 大文件 MD5 用流式计算

## 结论

AllahPan 后端的**核心 CRUD 链路稳定**，文件上传/下载/管理功能完整可用。文件处理管线（缩略图→OCR→ES索引）工作正常。存在 2 个 P0 严重 Bug 需要在生产部署前修复（ES 重建丢失索引、错误消息被吞噬）。其余 8 个中低优 Bug 在单用户场景下影响有限，但应在多用户上线前修复。
